# RetailPulse — Data Directory

## Folder structure

```
data/
├── raw/                        ← Place raw CSV here before running pipeline
│   ├── .gitkeep
│   └── retailpulse_transactions.csv   ← Generated by pipeline or placed manually
├── processed/                  ← Pipeline output (auto-generated, not committed)
│   ├── .gitkeep
│   └── retailpulse_clean.csv
├── sample/                     ← 500-row sample (auto-generated)
│   └── retailpulse_sample.csv
├── README.md                   ← This file
└── DATASET_SOURCE_AND_LICENCE.md
```

## Quick start (synthetic data — no download needed)

```bash
# From the project root with venv activated:
python src/pipeline.py --no-db
```

This generates `data/raw/retailpulse_transactions.csv` (10,000 rows, seed=42),
cleans it, and writes `data/processed/retailpulse_clean.csv`.

## Using a real dataset instead

1. Download the CSV from your chosen source (see `DATASET_SOURCE_AND_LICENCE.md`).
2. Verify the licence permits portfolio use.
3. Rename the file to `retailpulse_transactions.csv`.
4. Place it in `data/raw/`.
5. Ensure columns match the schema (see below). Rename columns if needed.
6. Run `python src/pipeline.py`.

## Required column schema

| Column         | Type    | Description                                      |
|----------------|---------|--------------------------------------------------|
| order_id       | string  | Unique order identifier                          |
| order_date     | date    | Transaction date (YYYY-MM-DD or parseable format)|
| product_id     | string  | Product identifier                               |
| product_name   | string  | Product display name                             |
| category       | string  | Product category                                 |
| sub_category   | string  | Product sub-category                             |
| quantity       | integer | Units purchased (must be > 0)                    |
| unit_price     | decimal | List price in INR (must be > 0)                  |
| discount       | decimal | Discount as fraction 0.0–1.0 (e.g., 0.15 = 15%) |
| sales_amount   | decimal | Post-discount revenue (must be > 0)              |
| profit         | decimal | Profit amount (may be negative)                  |
| state          | string  | Indian state name                                |
| city           | string  | City name                                        |
| payment_method | string  | Payment channel                                  |

## Important

- Do NOT commit large CSV files to Git (they are in `.gitignore`).
- Do NOT commit real customer data.
- The `.gitkeep` files mark empty directories for Git tracking.
