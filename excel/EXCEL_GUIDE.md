# RetailPulse — Excel Workbook Guide

## File: RetailPulse_Analysis.xlsx

## ⚠️ Data Notice

This workbook contains data from a **SYNTHETIC** dataset (seed=42, 10,000 rows).
It does NOT represent real company performance or actual Indian retail market data.

## How to Refresh the Workbook

The Excel workbook is generated by `src/excel_export.py`. When you run a fresh pipeline:

1. Run the pipeline to update processed data:
```powershell
python src/pipeline.py --no-db
```

2. Regenerate the Excel file:
```powershell
python src/excel_export.py
```

The existing `RetailPulse_Analysis.xlsx` will be overwritten with fresh data.

## Working with the Data in Excel

### Creating Pivot Tables

The "Cleaned Data" sheet is formatted for pivot analysis. To create a pivot:

1. Click anywhere in the Cleaned Data table
2. Insert → PivotTable → New Worksheet
3. Drag fields to Rows, Columns, Values, Filters

**Suggested pivot tables:**

| Analysis             | Rows       | Values         | Filters  |
|----------------------|------------|----------------|----------|
| Sales by category    | category   | SUM(sales_amount) | year  |
| Monthly trend        | year_month | SUM(sales_amount) | category |
| State performance    | state      | SUM(sales_amount) | —       |
| Top products         | product_name | SUM(sales_amount) | category |

### Useful Formulas

**Total sales as a percentage of grand total:**
```
=B2/SUM($B$2:$B$9)*100
```

**Month-over-month change:**
```
=(C3-C2)/C2*100
```

**Rank a list by sales:**
```
=RANK(B2,$B$2:$B$9,0)
```

## Limitations

- The "Cleaned Data" sheet contains a maximum of 5,000 rows (capped for Excel performance)
- For the full 10,000 rows, use the processed CSV: `data/processed/retailpulse_clean.csv`
- Excel formulas in this workbook are static — they do not live-query the MySQL database
- To get latest data, re-run the pipeline and regenerate the Excel file (see above)
