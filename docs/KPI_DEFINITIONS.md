# RetailPulse — KPI Definitions

## Overview

All KPIs in this project are computed from `sales_amount`, `profit`, `quantity`,
`unit_price`, `discount`, and `order_id` fields in the cleaned transactions table.

> **Data notice:** These KPIs are calculated on a SYNTHETIC dataset.
> They demonstrate analytical methodology, not real business performance.

---

## KPI 1 — Total Sales

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Sum of `sales_amount` across all clean rows                 |
| Formula     | `SUM(sales_amount)`                                         |
| Unit        | INR (Indian Rupees)                                         |
| Revenue type| Post-discount revenue (not gross list-price revenue)        |
| Limitation  | Does not account for returns, cancellations, or refunds     |
| SQL         | `SELECT ROUND(SUM(sales_amount), 2) AS total_sales FROM fact_sales` |

---

## KPI 2 — Total Orders

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Count of distinct order_id values                           |
| Formula     | `COUNT(DISTINCT order_id)`                                  |
| Unit        | Count                                                       |
| Limitation  | One order_id may contain multiple product lines (rows)      |
| SQL         | `SELECT COUNT(DISTINCT order_id) FROM fact_sales`           |

---

## KPI 3 — Total Units Sold

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Sum of quantity across all rows                             |
| Formula     | `SUM(quantity)`                                             |
| Unit        | Units (individual items)                                    |
| Limitation  | Counts items, not SKUs; a 2-unit purchase counts as 2       |

---

## KPI 4 — Average Order Value (AOV)

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Average total sales per unique order                        |
| Formula     | `SUM(sales_amount) / COUNT(DISTINCT order_id)`              |
| Unit        | INR per order                                               |
| Limitation  | Sensitive to high-value outlier orders                      |
| **Important**| Computed at order level (sum per order, then average), NOT as AVG(sales_amount) which gives row-level average |

---

## KPI 5 — Average Selling Price (ASP)

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Average list price per unit before discount                 |
| Formula     | `AVG(unit_price)`                                           |
| Unit        | INR per unit                                                |
| Limitation  | Pre-discount; does not reflect what customers actually paid |

---

## KPI 6 — Total Profit

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Sum of profit column across all rows                        |
| Formula     | `SUM(profit)`                                               |
| Unit        | INR                                                         |
| **Data note**| Profit is SYNTHETIC. Generated by applying simulated margin rates per category. Does not reflect real cost structures |

---

## KPI 7 — Profit Margin %

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Total profit as a percentage of total sales                 |
| Formula     | `(SUM(profit) / SUM(sales_amount)) × 100`                  |
| Unit        | Percentage                                                  |
| Limitation  | Blended margin; individual category margins differ          |

---

## KPI 8 — Average Discount %

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Sales-weighted average discount rate                        |
| Formula     | `SUM(unit_price × quantity × discount) / SUM(unit_price × quantity) × 100` |
| Unit        | Percentage                                                  |
| **Note**    | Weighted by gross sales value, not by order count           |

---

## KPI 9 — Category Sales Share %

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Each category's sales as a % of total sales                 |
| Formula     | `SUM(sales_amount FOR category) / SUM(sales_amount ALL) × 100` |
| Unit        | Percentage                                                  |
| Use case    | Concentration analysis; Pareto identification               |

---

## KPI 10 — Month-over-Month (MoM) Growth %

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | % change in monthly sales vs. prior month                   |
| Formula     | `(Current Month Sales − Prior Month Sales) / Prior Month Sales × 100` |
| Unit        | Percentage                                                  |
| **Warning** | First month has no prior → NULL. Partial first/last months inflate/deflate % |
| SQL         | Use `LAG(monthly_sales) OVER (ORDER BY year_month)` window function |

---

## KPI 11 — Average Items per Order

| Item        | Detail                                                      |
|-------------|-------------------------------------------------------------|
| Definition  | Average total quantity per unique order                     |
| Formula     | `SUM(quantity) / COUNT(DISTINCT order_id)`                  |
| Unit        | Units per order                                             |

---

## Metric calculation consistency rule

All KPIs in the dashboard read from the same filtered DataFrame.
Applying a date or category filter reduces the base population consistently across all KPIs.
This ensures KPI cards, charts, and tables always agree with each other.

---

## What is NOT a KPI in this project

| Metric              | Reason excluded                                              |
|---------------------|--------------------------------------------------------------|
| Revenue per customer| No customer_id in the synthetic dataset                      |
| Customer retention  | No repeat customer tracking — cannot be calculated           |
| Return rate         | No return/cancellation data available                        |
| Gross margin        | Would require actual COGS data — not available               |
| EBITDA              | Requires operating expense data — not available              |
